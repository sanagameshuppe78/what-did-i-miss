# What Did I Miss?

**The Unread Problem** is a project designed to help users understand what they may have missed in their unread messages.

## Features
- Helps users review unread messages.
- Aims to make catching up on conversations easier.

## Technology
- React
- Vite
- TypeScript

## Running Locally
1. Install Node.js.
2. Open the project folder in a terminal.
3. Run `npm install`.
4. Run `npm run dev`.
